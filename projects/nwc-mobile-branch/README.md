## التسعير (`pricing/`)

| الملف | المحتوى |
|---|---|
| `mobile_branch_pricing.xlsx` | 18 بنداً مفككة إلى 183 مكوّناً بكمياتها ومصادرها، وملخص العرض، والبنود الاختيارية |
| `build/data.py` | بيانات المكوّنات: الكمية والسعر والعملة ودرجة الثقة والمصدر |
| `build/build.py` | يبني ملف الإكسل بالمعادلات من `data.py` |

لتحديث الأسعار: عدّل ورقة «المدخلات» أو عمود «سعر الوحدة» في الإكسل مباشرة، أو عدّل `data.py` ثم شغّل:

```bash
python3 projects/nwc-mobile-branch/pricing/build/build.py
```
