# قائمة التحقق قبل التقديم

## المستندات النظامية
- [ ] السجل التجاري ساري
- [ ] شهادة الزكاة والدخل سارية
- [ ] شهادة التأمينات الاجتماعية
- [ ] شهادة السعودة / نطاقات
- [ ] شهادة التصنيف (المجال والدرجة المطلوبة)
- [ ] شهادة الغرفة التجارية
- [ ] شهادة المحتوى المحلي / خطة المحتوى المحلي (إن طُلبت)
- [ ] الضمان الابتدائي: القيمة، المستفيد، الصلاحية، الصيغة المعتمدة
- [ ] إيصال شراء الكراسة

## العرض الفني
- [ ] الترتيب يطابق معايير التقييم
- [ ] كل معيار له رد صريح ودليل
- [ ] السير الذاتية موقّعة وتطابق الهيكل التنظيمي
- [ ] شهادات الإنجاز للمشاريع المذكورة مرفقة
- [ ] البرنامج الزمني يطابق المدة التعاقدية
- [ ] لا توجد أي أرقام مالية في المظروف الفني (إن كانت الكراسة تفصل المظاريف)
- [ ] مصفوفة المطابقة كاملة، والانحرافات موضحة أو محوّلة لاستفسارات

## العرض المالي
- [ ] جدول الكميات بنفس ترقيم ووحدات المالك، لا بنود فارغة
- [ ] المبلغ رقماً = كتابةً = مجموع الجدول = خطاب العرض
- [ ] الضريبة 15% محسوبة ومفصولة
- [ ] صلاحية العرض مطابقة للكراسة
- [ ] لا تحفظات ممنوعة
- [ ] التوقيع والختم على كل الصفحات المطلوبة

## الشكل والتقديم
- [ ] الصيغة والحجم المسموح على المنصة
- [ ] أسماء الملفات واضحة ومرقّمة
- [ ] رُفع قبل الموعد بوقت كافٍ (يُوصى بيوم عمل على الأقل)
