# دليل التفكيك حسب التخصص

> لكل تخصص: هيكل الأقسام المعتاد، كيف يُفكك البند، محركات التكلفة، التكاليف المخفية الشائعة، والفحوص. كل المعدلات إرشادية وتُعاير بسجلات الشركة.

## 1) إنشائي (خرسانة وحديد وأعمال ترابية)
- **الأقسام:** أعمال ترابية ← خرسانة عادية ← خرسانة مسلحة (قواعد، ميد، أعمدة، جدران، أسقف، درج) ← حديد التسليح ← عزل الأساسات.
- **التفكيك:** الخرسانة (م³ + هالك 2–5%) + الشدات (م² شدة لكل م³: قواعد ≈ 1–2، أعمدة ≈ 8–12، أسقف وكمرات ≈ 5–8) + المعالجة + فرق النجارة والصب (إنتاجية بالـ م³/يوم) + سقالات. الحديد بند مستقل بالطن (هالك 3–7%).
- **محركات التكلفة:** الحديد والخرسانة الجاهزة (60–75% من الهيكل).
- **مخفي غالباً:** المضخة، نزح المياه، تجارب المكعبات، الاختبارات، الحماية الكاثودية، فواصل التمدد، الإضافات للخرسانة (مقاومة الكبريتات/ميكروسيليكا).
- **فحوص:** نسبة الحديد كجم/م³ (إرشادياً للمباني العادية: قواعد 70–110، أعمدة 150–250، أسقف 90–130، المتوسط العام ≈ 80–160) — خارجها راجع الحصر.

## 2) معماري وتشطيبات
- **الأقسام:** مباني البلوك ← اللياسة ← العزل (مائي/حراري) ← الأرضيات والتكسيات ← الدهانات ← الأسقف المستعارة ← الأبواب والنوافذ ← الواجهات ← الأعمال المتنوعة (درابزين، مطابخ، مرايا...).
- **التفكيك:** مادة (م² + هالك حسب المقاس والنمط: 5% مستقيم، 10–15% مائل أو مقاس كبير) + مواد التثبيت (لاصق كجم/م²، روبة) + فرقة بإنتاجية م²/يوم + سقالات للأعمال العالية/الخارجية.
- **محركات التكلفة:** الحجر والرخام والبورسلين والواجهات والألمنيوم — مواد يحددها الاستشاري بالاسم أو بمواصفة؛ اطلب 3 عروض.
- **مخفي غالباً:** العينات والنماذج (Mock-ups)، الحماية بعد التركيب، التنظيف النهائي، الزوايا والأحرف، الفواصل، المعجون الإضافي للجدران غير المستوية، رفع المواد للأدوار العليا.
- **فحوص:** كل م² لياسة داخلية يقابله دهان أو تكسية؛ مساحات الأرضيات ≈ مساحة الأسقف المستعارة؛ مساحات البلوك مخصوم منها الفتحات.

## 3) كهرباء وتيار خفيف
- **الأقسام:** الإنارة والقوى (نقاط) ← الكشافات ← اللوحات ← الكابلات والحوامل ← التأريض والصواعق ← التيار الخفيف (بيانات، إنذار حريق، كاميرات، صوتيات) ← الاختبار والتشغيل.
- **التفكيك:** النقطة = مواسير (م.ط/نقطة) + أسلاك (م.ط/نقطة ≈ 3× طول الماسورة للدائرة) + علبة + جهاز + فني بإنتاجية نقاط/يوم. الكابلات بالمتر مع الهالك والأطراف.
- **محركات التكلفة:** اللوحات الرئيسية، الكابلات الكبيرة، الكشافات، أنظمة التيار الخفيف.
- **مخفي غالباً:** رسوم وتوصيل الشركة السعودية للكهرباء والمحولات (حدد المسؤولية)، المولد، مخططات التنفيذ، الاختبارات واعتماد الدفاع المدني لإنذار الحريق، البرمجة والتشغيل.
- **فحوص:** نقاط بدون لوحات، لوحات بدون تأريض، أطوال الكابلات مقابل المخطط، هبوط الجهد للكابلات الطويلة (يحسبه المصمم — نبّه إن غاب).

## 4) تكييف وتهوية
- **الأقسام:** الوحدات (سبليت، باكدج، VRF، تشيلر) ← مجاري الهواء والعزل ← المخارج ← التهوية والشفط ← مواسير المبرد/المياه المبردة ← التحكم ← الاختبار والموازنة TAB.
- **التفكيك:** الوحدة + الرفع والتركيب + مواسير التوصيل حتى طول محدد؛ مجاري الهواء بالمساحة السطحية م² (أو كجم صاج) + عزل + حوامل + فرقة.
- **محركات التكلفة:** الوحدات (عرض أسعار من الوكلاء بماركات القائمة المعتمدة)، مجاري الهواء.
- **مخفي غالباً:** الرافعات، القواعد الخرسانية ومانعات الاهتزاز، كهرباء الوحدات (حدد هل هي على الكهرباء أم التكييف)، الضمان الممتد، التشغيل والصيانة خلال فترة الضمان.
- **فحوص:** وحدات بدون TAB؛ باكدج بدون مجاري؛ مؤشر الأحمال (طن تبريد/م²) مقابل نوع المبنى — إن كان غريباً فالكميات أو التصميم يحتاج مراجعة.

## 5) سباكة ومكافحة حريق
- **الأقسام:** تغذية المياه ← الصرف والتهوية ← الأدوات الصحية ← السخانات والمضخات والخزانات ← شبكة الحريق (مواسير، رشاشات، صناديق، مضخات حريق) ← الاختبارات.
- **التفكيك:** النقطة = مواسير وقطع حتى المجمع + محبس + فني؛ الأداة الصحية = توريد كامل + تركيب.
- **محركات التكلفة:** مضخات الحريق والخزانات، الأدوات الصحية الفاخرة، مواسير الحريق.
- **مخفي غالباً:** اعتماد الدفاع المدني، اختبارات الضغط، خزانات أرضية وعلوية، توصيل المياه والصرف للشبكة العامة (رسوم شركة المياه الوطنية).
- **فحوص:** أدوات بدون نقاط تغذية/صرف؛ رشاشات بدون مواسير.

## 6) شبكات مياه وصرف
- تُسعّر الخطوط بالتفكيك الهندسي للخندق — راجع `.claude/skills/water-pricing/SKILL.md`. البنود العددية (توصيلات، محابس، غرف) من المكتبة.

## 7) طرق وأعمال خارجية
- **الأقسام:** تجهيز التأسيس ← تحت الأساس ← الأساس ← التشريب واللصق ← الأسفلت ← البردورات والأرصفة ← العلامات والإشارات والإنارة.
- **التفكيك:** الطبقات بالـ م³ مدموك مع معامل انضغاط/انتفاش (≈ 1.25–1.35 للمورد المفكك)، الأسفلت بالطن (الكثافة ≈ 2.3–2.4 طن/م³: 5 سم ≈ 0.12 طن/م²) — غالباً مقاول باطن.
- **مخفي غالباً:** تحويلات المرور، تجارب الدمك والكثافة، المسح، رفع وتعديل المناسيب للغرف القائمة.
- **فحوص:** أسفلت بدون تشريب؛ أحجام الطبقات = المساحة × السماكة.

## بند غير موجود في المكتبة؟
فكّكه بنفس المنطق: مواد (كمية لكل وحدة + هالك) + عمالة (فرقة ÷ إنتاجية) + معدات + باطن، واذكر مصدر كل معدل. وإن تكرر بين المشاريع فأضفه إلى `library/library.json` ثم شغّل `build_platform.py`.
