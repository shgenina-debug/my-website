# قوائم التحقق قبل تسليم العرض المالي

## وثائق المنافسة
- [ ] قراءة كراسة الشروط والمواصفات وكل الملاحق والردود على الاستفسارات.
- [ ] تحديد نوع العقد وطريقة القياس والدفع.
- [ ] تسجيل الضمانات والدفعة المقدمة والمحتجزات والغرامات وفترة الصيانة.
- [ ] التحقق من التصنيف المطلوب ومتطلبات المحتوى المحلي.

## الكميات
- [ ] مراجعة كميات البنود ذات القيمة الأعلى مع المخططات.
- [ ] رصد البنود الناقصة/المكررة/الغامضة وإرسال الاستفسارات.
- [ ] التأكد من وحدة القياس لكل بند (م³، م²، م.ط، طن، عدد، مقطوع).

## الأسعار
- [ ] كل سعر مادة له مصدر وتاريخ (عرض مورد/سعر سوق).
- [ ] ثلاثة عروض لمقاولي الباطن للأعمال الرئيسية، مع جدول مقارنة وتسوية.
- [ ] تكلفة العمالة محسوبة بالكامل (Fully-loaded) وتشمل الرسوم النظامية.
- [ ] الإنتاجيات معدلة للصيف ورمضان وظروف الموقع.
- [ ] الهالك والنقل والتحميل مضمّنة.

## الإضافات
- [ ] مصاريف الموقع محسوبة تفصيلياً × المدة.
- [ ] تكلفة الضمانات البنكية والتأمينات.
- [ ] تكلفة التمويل من التدفق النقدي.
- [ ] مبلغ الطوارئ مبني على سجل المخاطر.
- [ ] نسبة الربح معتمدة من الإدارة.

## الملخص والتسليم
- [ ] الأسعار في الجدول غير شاملة الضريبة، والضريبة 15% في الملخص (أو حسب نموذج الجهة).
- [ ] تطابق مجموع الجدول مع الملخص ومع خطاب العرض (أرقاماً وكتابة).
- [ ] لا توجد بنود غير مسعّرة أو بسعر صفر دون توضيح.
- [ ] الافتراضات والاستثناءات مكتوبة بوضوح.
- [ ] تحليل حساسية لأهم البنود (±10% في الحديد والخرسانة والعمالة).
- [ ] مدة صلاحية العرض مطابقة للكراسة.
- [ ] الالتزام بنموذج العرض المالي على منصة اعتماد حرفياً.
