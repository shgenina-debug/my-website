# منهجية التسعير وهيكل التكلفة

## 1. هيكل سعر العرض

```
التكلفة المباشرة (Direct Cost)
  + المصاريف غير المباشرة للموقع (Site Overheads)
  = تكلفة المشروع (Project Cost)
  + المصاريف العامة للشركة (Head-Office Overheads)
  + تكلفة التمويل والضمانات والتأمين
  + المخاطر والطوارئ (Contingency / Risk)
  = إجمالي التكلفة (Total Cost)
  + الربح (Profit / Margin)
  = سعر العرض قبل الضريبة
  + ضريبة القيمة المضافة 15%
  = سعر العرض النهائي
```

## 2. تحليل سعر البند (Unit Rate Analysis)

### المواد
`كمية المادة للوحدة × (1 + نسبة الهالك) × سعر التوريد للموقع`
- سعر التوريد للموقع = سعر المصنع + النقل + التحميل والتنزيل.
- نسب هالك استرشادية (تُعدّل حسب طبيعة المشروع):

| المادة | الهالك المعتاد |
|---|---|
| خرسانة جاهزة | 2% – 5% |
| حديد تسليح (قص وتكسيح وتراكب) | 3% – 7% |
| بلوك | 3% – 5% |
| بلاط وسيراميك | 5% – 10% |
| دهانات | 5% – 10% |
| أخشاب الشدات (حسب عدد مرات الاستخدام) | يُحسب بالاستهلاك |
| كابلات ومواسير | 3% – 5% |

### العمالة
`(تكلفة الفريق اليومية ÷ الإنتاجية اليومية) = تكلفة العمالة للوحدة`
- **تكلفة العامل الفعلية (Fully-loaded)** تشمل: الراتب + السكن + النقل + الإعاشة (إن وُجدت) + المقابل المالي ورخصة العمل + الإقامة + التأمين الطبي + التأمينات الاجتماعية (GOSI) + التأشيرة وتذاكر السفر + مكافأة نهاية الخدمة + الإجازات. انظر `saudi-regulations.md`.
- اقسم التكلفة الشهرية على أيام العمل الفعلية (≈ 26 يوماً) وطبّق معاملات خفض الإنتاجية:
  - فترة الصيف وحظر العمل وقت الظهيرة في المواقع المكشوفة.
  - شهر رمضان (ساعات عمل مخفضة).
  - المواقع البعيدة أو المرتفعة أو العمل الليلي.

### المعدات
`(التكلفة اليومية للمعدة + المشغل + الوقود) ÷ الإنتاجية اليومية`
- للمعدات المملوكة: الإهلاك + الصيانة + التأمين + تكلفة رأس المال.
- للمستأجرة: سعر الإيجار + التعبئة والتسريح (Mobilization).

### مقاولو الباطن
سعر عرض مقاول الباطن (بعد التسوية والمقارنة بين ثلاثة عروض على الأقل) + نسبة إشراف وتنسيق (عادةً 3% – 7%).

## 3. المصاريف غير المباشرة للموقع (تُحسب تفصيلياً)

| البند | طريقة الحساب |
|---|---|
| الجهاز الفني والإداري (مدير مشروع، مهندسون، مساحون، مراقب سلامة، محاسب…) | العدد × التكلفة الشهرية × المدة |
| المكاتب المؤقتة، المستودعات، دورات المياه | مبلغ مقطوع + تشغيل شهري |
| مرافق الموقع: كهرباء، مياه، اتصالات | شهرياً × المدة |
| السلامة والصحة المهنية (HSE) | شهرياً + مبلغ مقطوع |
| المختبرات والاختبارات | حسب خطة الجودة |
| السيارات ووسائل النقل | العدد × الإيجار الشهري × المدة |
| التسوير واللوحات والحراسة | مقطوع + شهري |
| المخططات التنفيذية وAs-built | مقطوع |
| التعبئة والتسريح (Mobilization / Demobilization) | مقطوع |
| التنظيف النهائي والتسليم | مقطوع |

**استرشادياً** تتراوح مصاريف الموقع بين 8% و15% من التكلفة المباشرة حسب حجم المشروع ومدته؛ استخدم النسبة فقط للتحقق من معقولية الحساب التفصيلي.

## 4. الإضافات الاسترشادية (للتحقق لا للاعتماد)

| المكون | النطاق المعتاد |
|---|---|
| المصاريف العامة للشركة | 3% – 7% |
| المخاطر والطوارئ | 2% – 10% (حسب سجل المخاطر) |
| الربح | 5% – 15% (حسب المنافسة والرغبة في الفوز) |
| تكلفة التمويل | حسب التدفق النقدي وسعر الفائدة/المرابحة |

## 5. التمويل والتدفق النقدي
- ارسم منحنى S للمصروفات مقابل المستخلصات الشهرية.
- احسب تأخر السداد المتوقع (عادةً 60–90 يوماً أو أكثر في بعض الجهات) وأثر المحتجزات والدفعة المقدمة واستردادها.
- تكلفة التمويل ≈ متوسط الرصيد السالب × معدل التمويل × المدة.

## 6. سجل المخاطر (Risk Register)
لكل خطر: الوصف، الاحتمال (%)، الأثر (ر.س)، القيمة المتوقعة = الاحتمال × الأثر، وخطة المعالجة. مجموع القيم المتوقعة للمخاطر غير المنقولة = مبلغ الطوارئ.
أمثلة شائعة: تذبذب أسعار الحديد والإسمنت، تأخر التصاريح، تغير منسوب المياه الجوفية، تأخر صرف المستخلصات، نقص العمالة، أعمال التنسيق مع الخدمات القائمة.

## 7. التوزيع على البنود
- **المتوازن (الموصى به):** توزيع الإضافات بنسبة ثابتة على كل البنود حسب تكلفتها المباشرة.
- بنود المصاريف العامة (Preliminaries) إن وُجدت في الجدول تُسعّر بقيمتها الفعلية.
- **تجنّب** التسعير غير المتوازن (رفع البنود المبكرة أو البنود المتوقع زيادة كمياتها)؛ قد تعتبره لجنة فحص العروض سبباً للاستبعاد أو طلب التبرير.
