# إنتاجيات مرجعية لأعمال الشبكات (للمعايرة فقط)

> **تحذير:** نطاقات تقريبية عامة للتحقق من المعقولية، وليست بديلاً عن سجلات إنتاجية الشركة الفعلية.
> عدّلها حسب: العمق، نوع التربة (رمل / صخر)، المياه الجوفية، العمل داخل الأحياء أو في أرض مفتوحة، ساعات العمل المسموحة، الحرارة في الصيف، رمضان.

| النشاط | الفرقة النموذجية | الإنتاجية اليومية الإرشادية |
|---|---|---|
| حفر خندق في تربة عادية (حفار متوسط) | حفار + مشغل + عاملان | 250–450 م³/يوم |
| حفر في صخر (كسارة هيدروليكية) | حفار بكسارة + مشغل | 30–80 م³/يوم |
| تمديد HDPE حتى 160 مم شاملاً اللحام | فني لحام + 3–4 عمال + معدة لحام | 150–300 م.ط/يوم |
| تمديد HDPE 200–400 مم | فني لحام + 4 عمال + معدات رفع | 80–150 م.ط/يوم |
| تمديد DI 100–300 مم | سبّاك + 4 عمال + حفار للرفع | 80–150 م.ط/يوم |
| تمديد DI 400–600 مم | سبّاك + 5 عمال + حفار/رافعة | 40–80 م.ط/يوم |
| تمديد DI/GRP 800–1200 مم | فرقة كاملة + رافعة | 20–40 م.ط/يوم |
| تمديد خط صرف uPVC/GRP بالجاذبية 200–400 مم (مع ضبط الميول) | مساح + 4 عمال + حفار | 50–100 م.ط/يوم |
| فرشة وتغليف رملي | لودر صغير + 3 عمال | 60–120 م³/يوم |
| ردم ودمك على طبقات | لودر + هزاز + 2 عمال | 150–300 م³/يوم |
| قص وإعادة أسفلت (مقاول باطن غالباً) | — | 300–800 م²/يوم |
| توصيلة منزلية مياه | فني + 2 عمال | 4–8 توصيلات/يوم |
| توصيلة منزلية صرف | فني + 3 عمال | 3–6 توصيلات/يوم |
| غرفة تفتيش مسبقة الصب حتى 3 م | حفار + رافعة + 4 عمال | 1–3 غرف/يوم |
| اختبار ضغط مقطع | فني + عاملان + مضخة اختبار | 300–1000 م.ط/يوم (حسب طول المقطع) |

## معاملات تعديل شائعة (اضرب الإنتاجية بها)
| الظرف | المعامل الإرشادي |
|---|---|
| عمل داخل حي سكني مزدحم / تحويلات مرورية | 0.6–0.8 |
| مياه جوفية مع نزح | 0.5–0.75 |
| عمق أكبر من 3 م مع صناديق تدعيم | 0.6–0.8 |
| ساعات عمل ليلية فقط | 0.7–0.85 |
| أشهر الصيف (قيود العمل وقت الظهيرة) | 0.85–0.9 |
| رمضان | 0.75–0.85 |
