# my-website — فريق وكلاء مشاريع المياه

فريق من الوكلاء المتخصصين في Claude Code لشركة مقاولات تعمل في مشاريع المياه والصرف الصحي في السعودية.

| الوكيل | ماذا يعمل | مثال طلب |
|---|---|---|
| `tender-scout` | يبحث عن المنافسات والفرص ويقيّمها | «استخدم tender-scout وابحث عن منافسات شبكات المياه في الرياض والشرقية هذا الشهر» |
| `water-pricing-engineer` | تسعير هندسي بتفكيك البنود وتحليل كامل | «سعّر جدول الكميات المرفق بوكيل water-pricing-engineer» |
| `proposal-writer` | العرض الفني والمالي | «جهّز العرض الفني والمالي لهذه الكراسة» |
| `nwc-technical-responder` | الردود الفنية على استفسارات المياه الوطنية والاستشاري | «اكتب رداً فنياً على ملاحظات الاستشاري على اعتماد أنابيب GRP» |
| `saudi-project-pricing` | تسعير عام لمشاريع المقاولات | — |

## أول خطوة
املأ **`.claude/company/profile.md`** (التصنيف، النطاق، الخبرات، الكوادر، الموردون، سياسات التسعير). كل الوكلاء يعتمدون عليه.

## منصة التسعير
افتح `pricing-platform/index.html` في المتصفح (لا تحتاج إنترنت):
- مكتبة أسعار الأنشطة، تفكيك هندسي للخطوط (عرض وعمق الخندق، حفر، صخر، فرشة، تغليف، ردم، فائض، تدعيم، أسفلت)، بنود عددية بتحليل سعر الوحدة، مصاريف الموقع والإضافات.
- النتائج: ملخص العرض، الجدول المسعّر، توزيع التكلفة، مؤشرات الخطوط، باريتو، الحساسية، الفحوص الهندسية واتساق المدة.
- استيراد/حفظ JSON، تصدير ملف للحاسبة وCSV، وطباعة.

## الأدوات
- `.claude/skills/water-pricing/scripts/water_assemblies.py` — التفكيك الهندسي للخطوط.
- `.claude/skills/saudi-project-pricing/scripts/pricing_calc.py` — التسعير والملخص والحساسية.
- `.claude/skills/tender-scouting/scripts/score_opportunities.py` — ترتيب الفرص وقرار المشاركة.

تفاصيل سير العمل في `CLAUDE.md`. كل الأسعار في الأمثلة **توضيحية** ويجب استبدالها بعروض موردين وسجلات الشركة.
