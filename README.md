# my-website — فريق وكلاء المقاولات ومنصة التسعير

فريق من الوكلاء المتخصصين في Claude Code لشركة مقاولات سعودية، مع منصة تسعير هندسي عامة.

| الوكيل | ماذا يعمل | مثال طلب |
|---|---|---|
| `pricing-engineer` | تسعير هندسي لأي نوع مشروع مع تفكيك كل بند | «سعّر مشروع إلكتروميكانيك لمبنى إداري — الجدول مرفق» / «اعمل تقدير لتشطيبات فيلا معمارياً» |
| `proposal-writer` | العرض الفني والمالي | «جهّز العرض الفني والمالي لهذه الكراسة» |
| `nwc-technical-responder` | الردود الفنية على استفسارات المياه الوطنية والاستشاري | «اكتب رداً فنياً على ملاحظات الاستشاري على اعتماد أنابيب GRP» |
| `tender-scout` | البحث عن المنافسات والفرص وتقييمها | «ابحث عن منافسات شبكات المياه في الرياض والشرقية هذا الشهر» |

## أول خطوة
املأ **`.claude/company/profile.md`** (التصنيف، النطاق، الخبرات، الكوادر، الموردون، سياسات التسعير). كل الوكلاء يعتمدون عليه.

## التسعير حسب نوع المشروع
| النوع | التخصصات |
|---|---|
| مبنى متكامل | إنشائي + معماري + كهرباء + تكييف + سباكة وحريق |
| إلكتروميكانيك | كهرباء وتيار خفيف + تكييف وتهوية + سباكة ومكافحة حريق |
| معماري وتشطيبات | بلوك، لياسة، عزل، أرضيات وتكسيات، دهانات، أسقف، أبواب ونوافذ |
| إنشائي | أعمال ترابية، خرسانة، حديد، عزل أساسات |
| كهرباء / تكييف / سباكة وحريق | كل تخصص منفرداً |
| شبكات مياه وصرف | تفكيك هندسي للخنادق + توصيلات ومحابس وغرف |
| طرق / بنية تحتية | طبقات، أسفلت، بردورات، إنترلوك، علامات |

مكتبة البنود (`.claude/skills/cost-estimating/library/library.json`) فيها 65 بنداً مفككاً إلى مواد وعمالة ومعدات بمعدلات إرشادية، **وبدون أي أسعار**. الأسعار تُدخل لكل مشروع مرة واحدة لكل مورد.

## منصة التسعير
افتح `pricing-platform/index.html` في المتصفح (لا تحتاج إنترنت):
1. **مشروع جديد** ← اختر النوع.
2. **مكتبة البنود** ← حدّد البنود وأدخل الكميات.
3. **جدول الكميات والتفكيك** ← عدّل الوصف والمعدلات أو أضف بنوداً حرة.
4. **أسعار الموارد** ← سعر كل مورد مرة واحدة.
5. **المصاريف والإضافات** ثم **النتائج**: ملخص العرض حسب التخصص، سعر م²، الجدول المسعّر، باريتو، الحساسية، والفحوص الهندسية.

استيراد/حفظ JSON (نفس ملفات الوكيل)، تصدير CSV، وطباعة.
